# Quick Start Pro

Driving school management system — Team Xenon, COE454.

## Tech Stack
- Frontend: React 19, TypeScript, Vite, Tailwind CSS
- Backend: Node.js, Express.js, TypeScript
- Database: PostgreSQL (Supabase)
- Auth: JWT + bcrypt

## Prerequisites
- Node.js v20+
- npm

## Setup

### Frontend
```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

### Backend
```bash
cd backend
npm install
cp .env.example .env
# Fill in .env values
npm run dev
```
